# Бэкенд проекта

Основа Django + Django REST Framework для локальной разработки.
Реализованы проверочный запрос и тестовый календарь для соединения с фронтендом.
Реальные данные NASA ещё не подключены.

## Первый запуск на macOS

Выполнить в папке `backend` (Python 3.12 или новее):

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Если окружение уже установлено, при следующем запуске достаточно:

```bash
source .venv/bin/activate
python manage.py runserver
```

Открыть http://127.0.0.1:8000/api/v1/health/.
В браузере DRF может показывать оформленную страницу с JSON-ответом.

```json
{"status": "ok", "data_ready": false}
```

`status: ok` означает, что сервер отвечает.
`data_ready: false` сейчас задано явно: загрузка реальных данных пока не реализована.
Остановить сервер — Ctrl+C.

## Что находится в папке

- `manage.py` — команды Django: запуск, миграции, проверки.
- `config/settings.py` — настройки, подключённые приложения и SQLite.
- `config/urls.py` — общий список адресов.
- `fires/urls.py` — адреса нашего API.
- `fires/views.py` — обработчики запросов.
- `fires/serializers.py` — проверка параметров календаря.
- `fires/demo_data.py` — выдуманные примеры для разработки интерфейса.
- `fires/models.py` — место для будущих моделей, сейчас пустое.
- `requirements.txt` — версии библиотек для команды.

Next.js на localhost:3000 и 127.0.0.1:3000 разрешён настройками CORS.
Настройки рассчитаны на локальную разработку; публикация сервера будет отдельным этапом.

## Тестовые данные для фронтенда

Сначала получить настройки:

```text
GET /api/v1/meta/
```

Затем запросить месяц:

```text
GET /api/v1/calendar/?region_id=example-region&year=2024&month=8
```

В ответе `days` содержит 31 день августа 2024 года:

- 14 августа — 12 активных ячеек MODIS и 18 VIIRS;
- 15 августа — ноль для обоих приборов;
- остальные дни — `null`, данных нет.

Все числа выдуманы. Ответы содержат `is_demo: true`; фронтенд должен
показывать подпись «Тестовые данные». `health.data_ready` остаётся `false`,
потому что реальных данных NASA ещё нет.

Пока поддерживаются только `example-region` и август 2024 года.
Отсутствующие параметры, другой регион, месяц или год дают HTTP 400.
Запросы только GET; POST возвращает HTTP 405.

Дальнейший шаг — показать эти данные в календаре Next.js.
