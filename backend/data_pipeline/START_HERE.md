# Текущий этап: календарь из настоящих данных

Рабочая папка: `/Users/andrejkot/Downloads/projectHackaton/data_pipeline`.

- Код получения NASA и чтения базы: `fires_data/`.
- Локальные настройки: `.env`.
- База: `var/fires.sqlite3`.
- Описание для Саши: `README.md` и `LIVE_STATUS.md`.

API проверен. В базе 4 893 436 исходных наблюдений. Август 2024 загружен целиком
по всему миру для MODIS и VIIRS NOAA-20: 31 день для каждого источника.

## Посмотреть базу

Команды выполнять из папки `data_pipeline`:

```bash
python3 -m fires_data status
```

## Получить дневные показатели календаря

```bash
python3 -m fires_data calendar --scope world --from 2024-08-01 --to 2024-08-31
```

Команда читает локальную базу и выдаёт JSON. Для прямоугольной области:

```bash
python3 -m fires_data calendar --scope world --from 2024-08-01 --to 2024-08-31 --bbox 22 44 41 53
```

В результате отдельно показаны MODIS и VIIRS: сколько получено наблюдений и
сколько клеток общей сетки было активно за каждый UTC-день. Прямоугольник —
приблизительная область, не точный контур страны. Метод описан в `GRID_METHOD.md`.

Сумма активных клеток по дням называется ячейко-днями. Это не количество отдельных
пожаров. Базовый календарь остаётся без калибровки. Отдельный эксперимент поправки
и его ограниченная проверка запускаются командой ниже.

## Проверить экспериментальную поправку

```bash
python3 -m fires_data calibrate --scope world --from 2024-08-01 --to 2024-08-31 --split 2024-08-22 --bbox 22 44 41 53
```

Команда подбирает масштабную поправку на 1–21 августа и проверяет на 22–31 августа.
Поправка отдельная, исходные ряды сохраняются. Условия описаны в
`CALIBRATION_METHOD.md`; результат не применяется автоматически ко всем территориям.
